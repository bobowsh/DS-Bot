### 1. 启动后窗口被压在终端后面（PR #8 未修完）
- 证据：`%APPDATA%\LinkBot\logs\main.log` 17:35:52 `team window shown (behind)`；11-06 同流程是 `(focused)`
- 根因（小柚子定位）：`#reveal` / `#crossfade` 在 `behind` 分支**故意不抢焦点**（只 flashFrame）
- 待修：交接完成一律前置（minimized 除外）

### 2. 左下角 LinkBot 图标点了没反应、图标消失（PR #8 未修完）
- 组件：`ds-bot/src/client/sidebar.js` 的 `BotReturn`，注册在 `sidebar.footer.action`（id `bot-return`, order −300）
- 行为：只有 `mode === 'agent'` 才渲染，点击走 `actions.setSurface('bot')`
- 推测（**未验证**）：点击后 `setSurface('bot')` 生效、组件按设计卸载（图标消失），但 `index.js` 的 `setPlain(isAgentSessionId(main))` 可能把会话重新判成 DSH Agent Session，把 Bot 替换又撤掉 → 界面没变

### 3. 经典 Agent 模式切换入口消失
- 根因确认：**上游提交 `26479364`（2026-11-04）"Remove classic Agent mode switch from account menu"**
- 上游理由：避免账号菜单重复一个很少用的切换，只保留「设置 → 通用 → 模式」
- 用户决定：**不恢复原菜单项，另加一个按钮**
- 我们的额外理由：Agent 模式会撤掉整个 Bot 界面，返回按钮一旦失效就没有退路

### 4. 环境类坑（非代码）
- `ELECTRON_RUN_AS_NODE=1` 残留 → electron 以 Node 模式起、不建 GUI
- 开始菜单快捷方式 TargetPath 指向不存在的 `D:\LinkBot.exe`（真 exe 在 `D:\LinkBot\LinkBot.exe`）

## 七、教训（写给下一次）

1. **一个人同时挂 2 个分支 + 5 个未完成项 = 失控**。串行不是口号，是硬约束：一个 PR 收口再开下一个。
2. **催得太密反而让 Bot 来回切上下文**，丢现场重读文件，比不催更慢。点名要给「降压打法」（一文件一清、先交结论再动手）。
3. **每次报「完成」必须有证据**：测试数字、日志行、文件路径，光说「好了」不算。
4. **dev 态和安装态差异大**（窗口焦点、单实例锁、环境变量），验收一律用**免安装包**跑，不在 dev 态下结论。
