## 环境坑

- `ELECTRON_RUN_AS_NODE=1` 残留在进程环境里会让 Electron 以纯 Node 模式启动、秒退。
  启动应用前确认这个变量不在环境里。
- `git fetch ssh://git@ssh.github.com:443/...` 会报 `Connection closed by ::1 port 443`；
  改用 `origin`（https）可用。
